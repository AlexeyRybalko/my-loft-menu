# MY Loft Menu

Mobile-first QR menu for MY Loft, based on the approved Figma frame.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm test
npm run build
```

## Content

Menu content currently lives in `app/menu-data.ts`. The data model is prepared for a later Google Sheets JSON source with a local fallback.
